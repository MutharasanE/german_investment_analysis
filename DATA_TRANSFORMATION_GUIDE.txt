1. MISSING VALUES
   ✓ trust_score: No missing (DV must be complete)
   ✓ accuracy_score: No missing after encoding
   ✓ num_features: No missing (parsed from decision string)
   ✓ confidence_score: No missing

2. OUTLIERS
   Check: Any trust_score > 7 or < 4?

   - is_counterfactual_b: SD should be ~0.48 (binary, roughly 50-50)

   - num_features: SD should be ~1.5 (range 3-9)
   - confidence_score: SD should be ~1.30 (range 1-10)
   - attention_flag: SD should be ~0.50 (binary, ~48-52%)

4. MULTICOLLINEARITY
   Check: Correlation matrix for X variables
   → If any |r| > 0.8: Consider removing one (redundant information)
   → Likely: confidence_score ↔ trust_score (different questions, moderate r~0.4)
   → Unlikely: is_counterfactual_b ↔ attention_flag (independent)

5. SCALE CONSISTENCY
   All predictors on different scales:
   - Binary variables (0-1): is_counterfactual_b, attention_flag
   - Ordinal (0-2): accuracy_score
   - Continuous (3-9): num_features
   - Continuous (1-10): confidence_score

   OLS does NOT require standardization, but coefficients will be on different scales.
   OPTION: Standardize if comparing coefficient magnitudes in publications.

6. REGRESSION ASSUMPTIONS (CHECK AFTER FITTING)
   a) Linearity: Relationships between X and Y are linear
      → Plot: Partial regression plots (X vs residuals)
      → If curved: Consider polynomial terms (unlikely needed here)

   b) Normality: Residuals ~ N(0, σ²)
      → Plot: Q-Q plot of residuals
      → Test: Shapiro-Wilk test (n=25 is borderline for strict normality)

   c) Homoscedasticity: Constant variance of residuals
      → Plot: Residuals vs Fitted values
      → Test: Breusch-Pagan test
      → If fails: Consider robust standard errors

   d) Independence: Observations uncorrelated
      → Assumption likely met (different experts, different stocks)
      → Check: Durbin-Watson statistic ≈ 2

   e) No Perfect Multicollinearity: No X perfectly predicted by others
      → Check: VIF < 5 for each predictor
      → Your data: Unlikely issue (n=25 > p=5)
"""

PSEUDOCODE = """
import pandas as pd
import re

# Load raw data
df = pd.read_csv('survey_detailed.csv')  # or from MongoDB

# STEP 1: Parse decision string
def extract_num_features(decision_str):
    match = re.search(r'features:([^|]+)', str(decision_str))
    return len(match.group(1).split(',')) if match else None

def extract_attention(decision_str):
    return 1 if 'attention:pass' in str(decision_str) else 0

df['num_features'] = df['decision'].apply(extract_num_features)
df['attention_flag'] = df['decision'].apply(extract_attention)

# STEP 2: Binary encode methods
df['is_counterfactual_a'] = (df['method_for_a'] == 'COUNTERFACTUAL').astype(int)
df['is_counterfactual_b'] = (df['method_for_b'] == 'COUNTERFACTUAL').astype(int)

# STEP 3: Ordinal encode accuracy
accuracy_map = {
    'No, they seem theoretical': 0,
    'Somewhat accurate': 1,
    'Yes, highly accurate': 2
}
df['accuracy_score'] = df['mechanics_feedback'].map(accuracy_map)

# STEP 4: Select regression variables
reg_data = df[[
    'trust_score',           # Y
    'is_counterfactual_b',   # X1
    'accuracy_score',        # X2
    'num_features',          # X3
    'confidence_score',      # X4
    'attention_flag'         # X5
]].copy()

# STEP 5: Check for missing values
print(reg_data.isnull().sum())  # Should be all zeros

# STEP 6: Descriptive statistics
print(reg_data.describe())

# STEP 7: Correlation matrix (check multicollinearity)
print(reg_data.corr())

# STEP 8: READY FOR OLS
import statsmodels.api as sm
X = sm.add_constant(reg_data.drop('trust_score', axis=1))
y = reg_data['trust_score']
model = sm.OLS(y, X).fit()
print(model.summary())
"""

print(PSEUDOCODE)
